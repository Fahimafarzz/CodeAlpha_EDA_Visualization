# CodeAlpha - Exploratory Data Analysis and Data Visualization

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) and Data Visualization using Python.

The main objective of this project is to analyze sales data, identify useful patterns and trends, and represent the results using different charts and visualizations.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- VS Code

## Dataset

The dataset contains sales information with the following columns:

- Product
- Category
- Sales
- Quantity
- Region

## Exploratory Data Analysis

The following analysis was performed:

1. Dataset structure was examined.
2. First few records were displayed.
3. Statistical information was analyzed.
4. Missing values were checked.
5. Duplicate records were checked.
6. Total, average, highest and lowest sales were calculated.
7. Category-wise sales were analyzed.
8. Region-wise sales were analyzed.
9. Product-wise sales were analyzed.
10. Outliers were examined.

## Data Visualizations

The following visualizations were created:

- Sales by Category
- Sales by Region
- Sales by Product
- Quantity Sold by Product
- Sales Distribution by Category
- Sales Outlier Analysis
- Sales Distribution Histogram
- Correlation Heatmap

## Key Insights

- Category-wise sales were analyzed to understand the performance of different categories.
- Region-wise sales were compared to identify differences between regions.
- Product-wise sales were analyzed to identify products with higher sales.
- Quantity sold was compared across different products.
- Sales distribution and possible outliers were examined.
- The relationship between Sales and Quantity was visualized using a correlation heatmap.

## Conclusion

This project demonstrates how Python can be used for data analysis and visualization.

Using Pandas, Matplotlib and Seaborn, the sales dataset was explored and meaningful patterns were identified through statistical analysis and visualizations.

The project helped in understanding the basic workflow of Exploratory Data Analysis and Data Visualization.
