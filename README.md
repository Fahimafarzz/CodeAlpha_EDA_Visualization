## 📌 Project Overview

This project focuses on **Exploratory Data Analysis (EDA) and Data Visualization** using Python. The objective is to explore sales data, identify meaningful patterns, analyze product and regional performance, and communicate findings through clear and informative visualizations.

The project demonstrates the practical application of Python libraries in data analysis, statistical exploration, and visual storytelling.

## 🎯 Objectives

- Understand the structure and characteristics of the dataset.
- Perform exploratory data analysis on sales data.
- Analyze sales performance across products, categories, and regions.
- Examine quantity sold and sales distributions.
- Identify potential outliers in the dataset.
- Create meaningful charts to communicate analytical findings.

## 📊 Dataset Description

The dataset contains sales-related information with the following columns:

| Column | Description |
|---|---|
| Product | Name of the product |
| Category | Category to which the product belongs |
| Sales | Sales value |
| Quantity | Number of units sold |
| Region | Geographical sales region |

## 🔍 Exploratory Data Analysis

The following operations were performed:

- Inspected the dataset structure and data types.
- Displayed the first few records.
- Generated descriptive statistical summaries.
- Checked for missing values.
- Identified duplicate records.

## 📈 Data Visualization

The following visualizations were created as part of the analysis:

1. **Sales by Category** — Compares sales across product categories.
2. **Sales by Region** — Examines differences in regional sales.
3. **Sales by Product** — Compares sales values across products.
4. **Quantity Sold by Product** — Visualizes the quantity of products sold.
5. **Sales Distribution by Category** — Explores the distribution of sales among categories.
6. **Sales Outlier Analysis** — Helps identify unusually high or low sales values.
7. **Sales Distribution Histogram** — Displays the distribution of sales values.
8. **Correlation Heatmap** — Visualizes correlations between numerical variables.

## ⚙️ Installation and Execution

### Prerequisites

- Python 3 installed on your system.
- Visual Studio Code or another Python editor.

### Step 1: Clone the Repository

```bash
git clone https://github.com/Fahimafarzz/CodeAlpha_EDA_Visualization.git
```

### Step 2: Navigate to the Project Directory

```bash
cd CodeAlpha_EDA_Visualization
```

### Step 3: Install Required Libraries

```bash
python -m pip install pandas matplotlib seaborn
```

On Windows, if you use the Python launcher, you can also run:

```bash
py -m pip install pandas matplotlib seaborn
```

### Step 4: Run the Python Script

```bash
py sales_analysis.py
```

Make sure `sales_data.csv` is present in the same directory as the Python script.
